## Overview

Cruise Saga is a modern frontend application built with [React](https://reactjs.org/) for managing cruise bookings and operations.

## Features

- User authentication
- Cruise booking management
- Real-time updates
- Responsive UI

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/cruise-saga.git
    ```
2. Navigate to the frontend directory:
    ```bash
    cd Clients/cruise-saga/frontend
    ```
3. Install dependencies:
    ```bash
    npm install
    ```

## Usage

Start the development server:
```bash
npm start
```
The app will be available at [http://localhost:3000](http://localhost:3000).

## Development

- Code is located in the `src` directory.
- Use `npm run build` to create a production build.
